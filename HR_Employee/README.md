### &#x09;HR-Employee Analytics

##### Project Overview

This project looks at employee data to get a picture of how workforce is distributed. It check factors such as salary, employee performance, employment status, whether they work remotely and how long employees have been with the company. The main focus is to compare these factor across different regions and departments.



To prepare the data, i cleaned it using Excel and Power query. Then I used SQl to analyze the data and answer different business questions. Finally, I built a Power Bi dashboard to present the results in a clear and easy to understand way.



This is a beginner level data analytics project that i created to practice the complete workflow, from cleaning and analyzing data to create visualizations in Power Bi. It helped me understand how the different steps of a data analytics project connect together.

###### 

##### Dataset

Source: [Messy Employee Dataset on Kaggle](https://www.kaggle.com/datasets/desolution01/messy-employee-dataset)

###### 

##### Tools Used

* Microsoft Excel - Data cleaning and preparation
* MySQL- Data analysis and SQL queries
* Power BI- Dashboard and data visualization



##### What I Did

* Cleaned and checked the employee dataset using Excel and Power Query
* Checked for missing and inconsistent data
* Wrote SQL queries using aggregation, filtering, grouping, date analysis and ranking
* Analyzed salary, performance, employee status, department, region and remote work
* Created KPIs and different visualizations in Power Bi
* Built an interactive dashboard to make the result easier to understand

##### Key Insights

* The dataset contain 1020 employees. Where 352 employee are Active, 312 are Inactive and 356 are Pending.
* Sales has the Highest average salary while Finance has the lowest average salary among department.
* The highest individual salary in the dataset which is approximately $119,972.
* HR has the highest number of employees with and Excellent performance score.
* 513 employees work remotely, while 507 do not.
* DevOps had the highest number of employees among the departments.
